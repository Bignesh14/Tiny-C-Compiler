# TinyC-Lite Compiler

A small, cross-platform compiler written in **C11** that compiles
a custom language called **TinyC-Lite** into valid C code, which
is then compiled by `gcc` into a native executable.

Built from scratch as a learning project — no libraries, no frameworks,
just standard C and a text editor.

---

## What is TinyC-Lite?

TinyC-Lite is a simple language designed for this project. It supports:

- Integer variables — `int x = 5;`
- Arithmetic — `+ - * /` with parentheses
- Comparisons — `> < == != >= <=`
- If / else blocks
- Reassignment — `x = 10;`
- Print statement — `print x;`
- Line comments — `# this is a comment`

### Example program

```c
# hello.tcl — TinyC-Lite source
int x = 5 + 3;
int y = 10;
if (y > 6) {
    print y;
} else {
    print x;
}
print x;
```

### What the compiler generates

```c
/* Generated by tcc — TinyC-Lite Compiler */
#include <stdio.h>

int main(void) {
    int x = (5 + 3);
    int y = 10;
    if (y > 6) {
        printf("%d\n", y);
    } else {
        printf("%d\n", x);
    }
    printf("%d\n", x);
    return 0;
}
```

## Compiler Architecture

```
Source (.tcl)
      │
      ▼
┌───────────┐
│   LEXER   │  lex.c / lex.h
│           │  characters → tokens
└───────────┘
      │
      ▼
┌───────────┐
│  PARSER   │  parser.c / parser.h / ast.h
│           │  tokens → Abstract Syntax Tree
└───────────┘
      │
      ▼
┌───────────┐
│ SEMANTIC  │  semcheck.c / semcheck.h
│ ANALYSIS  │  checks variables and declarations
└───────────┘
      │
      ▼
┌───────────┐
│ CODE GEN  │  codegen.c / codegen.h
│           │  AST → valid C source
└───────────┘
      │
      ▼
  output.c  →  gcc  →  ./myprog  →  output!
```

## File Structure

| File | Phase | Role |
|------|-------|------|
| `tcc.h` | All | Shared types — Token struct, TokenType enum |
| `lex.h` / `lex.c` | 1 — Lexer | Reads characters, produces tokens |
| `ast.h` | 2 — Parser | AST node struct and NodeType enum |
| `parser.h` / `parser.c` | 2 — Parser | Recursive descent parser — tokens → AST |
| `semcheck.h` / `semcheck.c` | 3 — Semantic | Symbol table, error detection |
| `codegen.h` / `codegen.c` | 4 — CodeGen | Walks AST, writes C source |
| `main.c` | 5 — Driver | CLI flags, ties all phases together |
| `Makefile` | All | Cross-platform build |

## Usage

```bash
# Full compile — TinyC-Lite source to running binary
./tcc hello.tcl -o hello
./hello

# Print token stream only
./tcc hello.tcl --tokens

# Print AST only
./tcc hello.tcl --ast

# Generate C file only, skip gcc
./tcc hello.tcl --emit-c -o hello

# Show help
./tcc --help
```

> On Windows replace `./tcc` with `./tcc.exe` and `./hello` with `./hello.exe`

## Language Grammar (BNF)

```
program    ::= statement*
statement  ::= var_decl | assign | if_stmt | print_stmt
var_decl   ::= 'int' IDENT '=' expr ';'
assign     ::= IDENT '=' expr ';'
if_stmt    ::= 'if' '(' cond ')' block ( 'else' block )?
print_stmt ::= 'print' expr ';'
block      ::= '{' statement* '}'
expr       ::= term ( ('+' | '-') term )*
term       ::= factor ( ('*' | '/') factor )*
factor     ::= NUM | IDENT | '(' expr ')' | '-' factor
cond       ::= expr ( '>' | '<' | '==' | '!=' | '>=' | '<=' ) expr
```
